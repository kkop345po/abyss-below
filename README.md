# 深淵之下 Abyss Below

以 Unity 與 C# 製作的 2D 像素風格海底探索遊戲。本儲存庫公開遊戲程式碼，展示玩家控制、戰鬥、探索與資料管理等系統的實作。

**[前往 itch.io 下載 Windows 遊戲](https://blackmiko0219.itch.io/abyssblone)**

## 遊戲介紹

從陸地出發，潛入不同深度的海域，探索沉船與洞穴、收集資源並提升能力。探索途中需要留意氧氣與體力，迎戰海洋怪物與 Boss，並掌握安全返回的時機。

遊戲包含海底探索、戰鬥、資源收集、商店與升級、釣魚、任務、成就及存檔等系統。

## 下載與遊玩

1. 從 itch.io 遊戲頁面下載 Windows 版本。
2. 將 ZIP 完整解壓縮。
3. 執行資料夾內的遊戲主程式 `.exe`。

請保留主程式旁的 `_Data` 資料夾、DLL 與其他輸出檔案。遊玩不需要安裝 Unity 編輯器。操作教學可參考 itch.io 頁面上的影片。

## 開發環境

- Unity 2022.3.62f3
- C#、Unity 2D Physics
- Unity Input System、TextMesh Pro、Universal Render Pipeline
- 完整專案另使用 DOTween 等第三方套件；這些套件未隨本儲存庫提供。

## 程式碼導覽

程式位於 `Assets/Scripts/`：

- `Player/`：陸地與水中玩家控制、生命、體力及互動。
- `Enemy/`、`Combat/`：敵人、Boss、受擊判定與投射物。
- `Oxygen/`：氧氣管理。
- `Inventory/`、`Shop/`、`升級/`：道具背包、商店與能力升級。
- `Fishing/`：釣魚、QTE 與獎勵。
- `QuestSystem/`、`Achievement/`、`Dialogue/`：任務、成就與對話。
- `SaveData/`：玩家資料與存檔。
- `場景/`：場景轉換、玩家生成、出生點與位置管理。
- `Rope/`：繩索與玩家抓取。
- `UI/`、`介面/`：介面控制。
- `音效/`、`Ambience/`、`視差背景/`：音訊、環境與背景表現。
- `Effects/`：視覺效果，包含玩家穿過物件時的精靈淡化元件。
- `開發工具/`：編輯器內測試工具。作弊核心、面板及位置測試快捷鍵以 `UNITY_EDITOR` 限制；一般輸出與 Development Build 不編譯這些功能。作弊場景傳送已停用。
